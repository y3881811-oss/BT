## ✨ 项目特点与重构计划

*   **技术栈迁移**：将原版的 Dart/Flutter 架构，完全迁移至 **Kotlin (原生 Android)**，减小包体大小，提升 TV 端运行流畅度。
*   **架构升级**：采用现代 Android 开发架构（如 Jetpack Compose / 原生 View 体系，可自行修改）。
*   **开源纯净**：所有源码全部公开，欢迎社区审查。

> ⚠️ **项目状态**：目前正在重写中（Work in Progress），部分功能可能尚未完善，欢迎提交 Issue 或 PR。

## 🚀 下载与安装

由于开发者没有本地电脑环境，本项目完全依赖 **GitHub Actions** 进行云端编译打包。

*   **下载最新测试版**：请前往本仓库顶部的 **Actions** 标签页，点击最新的绿色构建记录，在页面底部的 `Artifacts` 中下载对应的 APK 压缩包。
*   **正式发布版**：请前往 **Releases** 页面下载（当项目稳定后，我会在这里发布正式版）。

**版本兼容性：**
*   适用于 Android 5.1 及以上版本 (API 21+)。
*   完美适配 Android TV 遥控器操作。

## 🛠️ 如何自行编译

如果你想自行编译，可以点击本仓库绿色的 `Code` 按钮，选择 `Codespaces` 在云端打开编辑器，或者 Fork 到你的账号后，利用自带的 GitHub Actions 脚本进行编译。
